# ablation2d

The package behind Hands-on 3. A chained NCA reads a liver CT slice, one to four
microwave needles and their powers, and returns two maps from the same rollout:
the tissue that will die after five minutes of heating, and the vessels. The
vessels are never given as an input; the model has to find them, because they
carry heat away and notch the lesion.

```
notebooks/ablation_with_nca_TUTORIAL.ipynb   six TODOs in four cells
notebooks/ablation_with_nca_SOLUTION.ipynb   complete, runs top to bottom
notebooks/ablation_with_nca_SOLUTION.executed.html   the same, with outputs, from a Colab runtime
slides/tips_and_tricks_nca.html              the 10-minute talk before the session (P: presenter view)
```

Both notebooks are generated by `build_notebooks.py` and the deck by
`build_slides.py`. Edit those, never the outputs.

## The task

| | |
|---|---|
| input | 3 channels at 128 × 128, 2 mm: CT masked to the liver, needle shaft, power at the radiating slot |
| output | necrosis (Arrhenius damage) and vessels |
| labels | 3-D Pennes bioheat + microwave power deposition + Arrhenius damage, solved by the physics solvers of my PhD work (supervised by Prof. Caroline Essert and Juan Verde), sliced at the needle plane |
| corpus | 4 000 plans on 2 000 slices of 50 real livers, split by patient 35 / 5 / 10 |
| device | Medtronic Emprint HP, calibration provisional (ex vivo bovine liver, 17 °C) |

Burn time is fixed at five minutes. The label is solved in 3-D because a
one-voxel 2-D solve is an infinite slab and gives lesions 14 % too long.

## Results

Test plans with one or two needles (659 plans, 10 patients the model never saw):

| | necrosis DSC | vessel F1 | parameters |
|---|---|---|---|
| reference C-NCA: anatomy first, 5 blocks per step, K = 4 | 0.907 | 0.838 | 46 240 |
| session C-NCA, the notebook's 5-minute budget\* (mean of 3 seeds) | 0.833 | 0.769 | 10 416 |
| device-chart sphere (power and time only) | 0.793 | - | - |
| best single Hounsfield threshold | - | 0.436 | - |
| dilated CNN, same parameters and training | 0.912 | 0.804 | 40 340 |

\* measured as 180 s on a TITAN V, our stand-in for a Colab T4.

The automaton reads the anatomy first (a few steps on the CT alone, needle
channels empty) and then heats with the vessel map held fixed, so the vessels it
finds cannot depend on the plan: vessel F1 is 0.836 under random plans, 250 W,
or tips outside the liver alike, and it finds 56 % of the vessels inside a
lesion, where a single rollout found 8 %. Every cell updates at every step, so
the model is deterministic. It stops at the K chosen on validation.

Every number, with how it was measured, is in `docs/RESULTS.md`, generated by
`scripts/write_results.py`.

## Layout

```
ablation2d/
  model.py        the chained NCA, its losses and metrics
  train.py        the training loop; the tricks from the talk are marked # TRICK n
  data.py         the corpus, kept as uint8 on the GPU
  evaluate.py     scoring and the two baselines (device-chart sphere, HU threshold)
  webplanner.py   the live planner: the NCA as WebGL shaders (webplanner.js)
  ui.py           the same planner with ipywidgets sliders, as a fallback
  live.py         the training dashboard
  viz.py          figures
  channels.py     painting a plan into input channels
  anatomy.py, device.py, plans.py, physics.py, generate.py   the corpus side
scripts/
  train_model.py        train a model:   --config full --epochs 240 --name liver
  score_checkpoint.py   score any checkpoint with the current evaluation code
  write_results.py      docs/RESULTS.md
  run_study.py          the comparative studies the slides quote
  make_figures.py       figures/
  test_notebook.py      execute both notebooks end to end
  gen_dataset.py, extract_real_*.py, make_liver_masked_corpus.py, datasheet.py   the corpus (need the solver)
tests/                  pytest, CPU only
```

## Reproducing

```bash
pip install -r ../requirements.txt
python scripts/train_model.py --config full --epochs 240 --name liver   # the reference model
python scripts/score_checkpoint.py checkpoints/ablation_cnca_liver.pt
python scripts/write_results.py
python build_notebooks.py && python build_slides.py
```

Training and the notebook need only the shipped `.npz` corpus. Building the
corpus itself needs the solver stack, which is not public.

## Testing

```bash
python -m pytest tests                       # CPU, about a minute
python scripts/test_notebook.py --kernel K   # executes both notebooks on CPU in QUICK mode
```

`test_notebook.py` runs the SOLUTION notebook twice (training the notebook's own
model, then loading the shipped checkpoint) and checks that the TUTORIAL stops at
its first TODO. `tests/test_webplanner.py` runs the browser planner in headless
Chromium and checks that the shader rollout matches PyTorch; it is skipped when
Playwright is not installed.

## Caveats

The labels inherit the device calibration, which is provisional and not
clinically validated, and the model is 2-D. The corpus is de-identified patient
CT: see `data/DATASHEET.md` for what it contains and its terms.
